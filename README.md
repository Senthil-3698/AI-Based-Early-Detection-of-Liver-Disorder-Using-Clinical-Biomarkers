# Intelligent Liver Disease Prediction Suite

## 🎯 Project Overview

Engineered an end-to-end ML pipeline benchmarking CatBoost, LightGBM, XGBoost, Random Forest, SVM, Logistic Regression, and MLP on liver disease datasets with automated evaluation dashboards. **Achieved 99.74% accuracy and 99.49% precision** using Random Forest classifier.

Documented complete methodology, experiments, and deployment workflow in a comprehensive project report, enabling reproducible research and streamlined handover for production deployment.

## 📊 Key Performance Metrics

- **Best Model:** Random Forest Classifier
- **Accuracy:** 99.74%
- **Precision:** 99.49%
- **F1 Score:** 99.54%
- **ROC-AUC:** 99.99%
